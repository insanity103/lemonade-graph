## 1. Update Cadence & Content Types

### How Often Do Top Sword RPGs Update?

| Game | Cadence | Pattern |
|------|---------|---------|
| **Blox Fruits** | Every 2–8 weeks (major), with hotfixes within 24–72 hrs post-launch | Slower but massive updates; 30 major updates in ~7 years. Early updates were rapid (every 1–2 weeks), mature updates space to 2–4 months |
| **King Legacy** | ~4–8 weeks for major updates | Similar to Blox Fruits; numbered updates with sub-versions (e.g., v2.281) |
| **Pet Simulator 99** | Fortnightly (bi-weekly) | Explicitly moved to a 2-week cycle; praised by press as an improvement over Pet Simulator X's irregular schedule |
| **Adopt Me!** | Weekly–biweekly with seasonal mega-updates | Consistent small content drops punctuated by holiday events |
| **Dress to Impress** | Biweekly with collaboration drops | Partnered with Charli XCX and Lady Gaga for viral spikes |

**Key Insight**: The optimal cadence for a sword RPG is **bi-weekly minor updates + monthly major updates + quarterly mega-updates**. This balances dev capacity with player expectation.

### Update Type Impact Ranking

Ranked by historical player spike magnitude (Blox Fruits data):

| Rank | Update Type | Spike Size | Duration | Example |
|------|-------------|------------|----------|---------|
| 1 | **New World/Sea Expansion** | Massive (3–5x baseline) | 2–4 weeks | Update 8 (Second Sea), Update 20 (Third Sea) |
| 2 | **New Fruit/Power System** | Large (2–3x) | 1–3 weeks | Dragon rework, Kitsune release, Control Rework (Update 29) |
| 3 | **New Game Mode** | Large (2–3x) | 2–4 weeks | Dungeon Mode (Update 29), Awakening Raids (Update 11) |
| 4 | **Major Rework (visually impactful)** | Medium-Large (2x) | 1–2 weeks | Sea 1 Rework (Update 30), Dark Blade reimagining |
| 5 | **Seasonal/Holiday Event** | Medium (1.5–2x) | 2–4 weeks | Halloween, Christmas, Easter events |
| 6 | **New Fighting Style/Weapon** | Medium (1.5x) | 1–2 weeks | Godhuman, Sanguine Art releases |
| 7 | **Balance/PvP Meta Shift** | Small-Medium (1.3x) | 1 week | Meta shake-ups drive PvP community engagement |
| 8 | **QoL/Bug Fixes** | Negligible | — | Important for retention but doesn't drive acquisition |

### Player Count Spike Duration After Updates

```
Update Launch → Spike Peak: 0–48 hours
Sustained Elevated Play: 3–7 days
Gradual Decline to New Baseline: 7–21 days
Return to Pre-Update Levels: 21–42 days (for minor updates)
```

**Critical**: Major updates (new world, new system) establish a **permanently higher baseline** — the game never fully returns to pre-update numbers. This is the compounding growth engine.

### Teaser/Hype Campaign Timeline (What Works)

Blox Fruits' proven pattern:

| Phase | Timing | Action |
|-------|--------|--------|
| **Sneak Peek** | T-14 days | Post cryptic image on Twitter/Discord |
| **Teaser 1** | T-10 days | Reveal one new feature (fruit name, island screenshot) |
| **Creator Leaks** | T-7 days | Give top YouTubers early access or hints |
| **Teaser 2** | T-5 days | Reveal second feature, code hint |
| **Countdown** | T-3 days | Daily reveals on social media |
| **Code Drop** | T-1 day | Release a hype code ("UPDATECOMING") |
| **Launch** | T-0 | Full update + launch codes + creator videos go live simultaneously |
| **Post-Launch Code** | T+3 days | Release another code to re-engage lapsed players |

## 3. Code Distribution as Growth Engine

### How Blox Fruits Codes Work

**What codes give:**
| Reward Type | Typical Value | Frequency |
|-------------|---------------|-----------|
| 2x Experience Boost | 20–30 minutes | Most common |
| Stat Reset | Free (normally costs Robux or in-game currency) | Common |
| Money | Small amounts (joke codes like `fudd10` = $1) | Rare |
| Titles | Exclusive vanity titles | Rare |
| Large 2x EXP | 1–2 hours (milestone codes like `1BILLION`) | Very rare, tied to milestones |

**Key Mechanic**: The 2x EXP duration **stacks** and **persists across rejoins**, making codes extremely valuable to active players.

### Code Distribution Channels & Strategy

Blox Fruits uses a **creator-first distribution model**:

| Channel | Timing | Purpose |
|---------|--------|---------|
| **YouTube Creators** (Zioles, Gamer Robot) | First 72 hours | Exclusive: Wiki notes "new codes from videos of Gamer Robot will not be listed here in the first three days following the video's release, as per request from Zioles" |
| **Official Discord** | T+0 to T+24 hrs | Core community gets codes alongside YouTube |
| **Twitter/X** (@BloxFruits) | T+24–48 hrs | Wider distribution |
| **Wiki/Code Sites** | T+72 hrs | Mass distribution after creator exclusivity window |

5. Free to implement, creates a permanent marketing army

### Code Expiration Strategy (FOMO Mechanics)

| Code Type | Lifespan | Purpose |
|-----------|----------|---------|
| **Permanent Creator Codes** | Never expire | Ongoing creator incentive |
| **Milestone Codes** (`1BILLION`, `3BVISITS`) | Days to weeks | Celebration + FOMO rush |
| **Update Codes** (`UPD14`, `UPD15`) | Days to weeks | Drive update-day traffic |
| **Event Codes** (`EASTEREXP`, `XmasExp`) | Hours to days | Seasonal FOMO |
| **Admin/Troll Codes** (`ADMIN_TROLL`, `SECRET_ADMIN`) | Hours | Surprise/engagement |

**The FOMO Curve**:
```
Code Announcement → Immediate redemption spike (60% of total redemptions)
                    → Content creator videos (T+0 to T+72)
                    → Wiki/code site listing (T+72)
                    → Gradual trickle (remaining 40%)
                    → Expiration → Players who missed out feel FOMO
                    → Next code: faster redemption (learned behavior)
```

### How Developers Work with Creators

**Blox Fruits' Creator Program Mechanics:**

1. **Early Code Access**: Creators get codes 72 hours before wiki publication
2. **Sneak Peek Previews**: Developers share teaser images/clips that creators can exclusively react to
3. **Admin Panel Events**: Developers host in-game events where admins spawn rare enemies/bosses, and creators film reactions
4. **Named Permanent Codes**: Creators get permanent codes with their name (see Section 3)
5. **No Formal Affiliate Program Needed**: The code system IS the affiliate program — it's self-sustaining

**What Makes a Roblox Sword RPG Go Viral on YouTube:**

1. **Visual Spectacle**: Over-the-top fruit/sword abilities that look dramatic on camera
2. **Discovery Content**: Hidden secrets, easter eggs, secret bosses
3. **Power Fantasy**: "I got the RAREST fruit and it's BROKEN" narratives
4. **Community Rivalry**: PvP drama, tier list debates, "who's the best player"
5. **Update Hype Cycle**: The 2-week buildup → launch → reaction pipeline
6. **Reaction Thumbnails**: Exaggerated faces + new content = clicks

### Wiki Community

The Blox Fruits Wiki (blox-fruits.fandom.com) has **1,500+ pages** maintained by dedicated community editors. King Legacy Wiki has **4,836 pages** with 22,261 edits.

**Why Wiki Matters**:
1. **SEO**: Wiki pages dominate Google search results for "[game name] codes", "[game name] fruits", etc.
2. **New Player Onboarding**: Leveling guides, fruit tier lists, progression paths
3. **Community Investment**: Players who edit wikis become evangelists
4. **Content Creator Resource**: YouTubers reference wikis for accurate info

**Wiki Strategy**:
- Officially endorse the wiki (link from game description)
- Assign 1–2 community managers to maintain accuracy
- Create a "Wiki Contributor" role in Discord
- Share update info with wiki editors early (under embargo)
- The wiki page for Blox Fruits notes: "new codes from videos of Gamer Robot will not be listed here in the first three days following the video's release, as per request from Zioles" — showing direct developer-wiki coordination
